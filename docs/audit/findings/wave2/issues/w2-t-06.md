[test] dos generadores EXIF escriben los mismos `exif_o1..8.jpg` con distinta geometría (12x8 vs 16x16, el último en ejecutarse gana)

## Resumen
`crates/image/tests/fixtures/generate_exif.py:27,121-126` genera `crates/image/tests/fixtures/jpeg/exif_o{1..8}.jpg` en 12x8 (vía `make_reference`) mientras `crates/image/tests/fixtures/generate_exif_orientations.py:17,53-64` genera los mismos nombres en 16x16 (`W, H = 16, 16`). Ningún test fija la geometría esperada de forma que proteja contra el cambio.

## Impacto
P3 — fixture no hermética. Regenerar con un script u otro cambia silenciosamente las dimensiones; tests futuros sensibles a geometría fallarían/pasarían según qué script se corriera por último.

## Pasos para reproducir
1. Inspección: `OUT_DIR = …/fixtures/jpeg` + bucle `for orientation in range(1, 9)` con `path = OUT_DIR / f"exif_o{orientation}.jpg"` (12x8 / 8x12) frente a `FIXTURES = "crates/image/tests/fixtures/jpeg"` + mismo bucle con `W, H = 16, 16`.
2. Repro destructivo (NO ejecutar sobre el árbol: muta fixtures commiteadas; hacerlo sobre copia en `/tmp`): `python3 crates/image/tests/fixtures/generate_exif.py && python3 crates/image/tests/fixtures/generate_exif_orientations.py && ls -l crates/image/tests/fixtures/jpeg/exif_o*.jpg` (requiere Pillow).
