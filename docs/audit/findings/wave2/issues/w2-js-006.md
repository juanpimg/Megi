[js] setTimeout con delay string no aplica ToNumber (dispara de inmediato)

## Resumen
El delay de timer usa `JsValue::as_number` (sin coerción `ToNumber`) + `unwrap_or(0.0)`; un string numérico como `"100"` cae a retardo 0 y dispara de inmediato.

## Impacto
P3 — desviación de temporización: `setTimeout(fn, "100")` debería esperar ~100ms (ToNumber), pero dispara en ~50ms-tick inmediato.

## Pasos para reproducir
1. `cargo run --release --bin repro-f2-js` (caso R9).

## Esperado vs observado
Esperado: `string-delay fired at t=50 (spec: false): false`.
Observado: `R9 string-delay fired at t=50 (spec: false): true`.

## Evidencia literal
```
R9 string-delay fired at t=50 (spec: false): true
```
Código: `events.rs:1603-1606` usa `JsValue::as_number` (sin ToNumber) + `unwrap_or(0.0)`; el string `"100"` cae a retardo 0.

Commit: 3c06db8

## Workaround
Pasar siempre delays numéricos (`Number(d)` en JS llamante).
