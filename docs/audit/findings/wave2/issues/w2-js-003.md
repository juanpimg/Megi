[js] CustomEvent cancelable por defecto true (spec: false)

## Resumen
El constructor `CustomEvent` fija `cancelable=true` literal e ignora el valor por defecto de la spec (`false`) / la init-dict.

## Impacto
P2 — contrato observable roto: `new CustomEvent('x').cancelable === true` cuando la DOM spec exige `false` por defecto. `preventDefault()` parece tener efecto donde no debería.

## Pasos para reproducir
1. `cargo run --release --bin repro-f2-js` (caso R5).

## Esperado vs observado
Esperado: `new CustomEvent('x').cancelable === false` sin init-dict.
Observado: `R5 CustomEvent cancelable default: true`.

## Evidencia literal
```
R5 CustomEvent cancelable default: true
```
Código: `events.rs:501` fija `cancelable=true` literal (`build_event(..., bubbles, true, detail)`), mientras `event_constructor` (`465-472`) sí lee la init-dict.

Commit: 3c06db8

## Workaround
Pasar siempre `{cancelable:false}` explícito al construir `CustomEvent`.
