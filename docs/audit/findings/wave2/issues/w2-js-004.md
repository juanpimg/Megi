[js] document.writeln no anexa newline (idéntico a write)

## Resumen
`document.writeln` está registrado con la misma función que `document.write`, sin anexar `\n`.

## Impacto
P3 — contrato roto de bajo impacto: `writeln("a"); writeln("b")` produce `"ab"` en vez de `"a\nb"`.

## Pasos para reproducir
1. `cargo run --release --bin repro-f2-js` (caso R4).

## Esperado vs observado
Esperado: body `"a\nb"`.
Observado: `R4 writeln body text: "ab"`.

## Evidencia literal
```
R4 writeln body text: "ab"
```
Código: `runtime.rs:1349` registra `("writeln", 1, document_write)` — misma función que `write`, sin anexar `\n`.

Commit: 3c06db8

## Workaround
Usar `document.write(x + "\n")` en vez de `writeln`.
