El proyectoThe project

Un navegador hecho a manoA browser built by hand

Megi construye su propio motor web desde cero: descarga las páginas, lee el HTML y el CSS, coloca cada caja y dibuja el resultado. El objetivo es un navegador independiente, abierto y verificable, sin atajos. Megi builds its own web engine from the ground up: it downloads pages, parses HTML and CSS, lays out every box and draws the result. The goal is an independent, open and verifiable browser, with no shortcuts.

Independiente de verdadTruly independent

No es una copia de Chrome, Firefox ni Safari. El motor se escribe desde cero en Rust, sin reutilizar el código de otro navegador. It is not a copy of Chrome, Firefox or Safari. The engine is written from scratch in Rust, without reusing another browser's code.

Fiel a los estándaresTrue to the standards

Cada comportamiento sigue las especificaciones oficiales de la web y se comprueba con sus pruebas públicas. El parser HTML5 ya pasa el 100 % de las pruebas de referencia. Every behaviour follows the web's official specifications and is checked with their public tests. The HTML5 parser already passes 100% of the reference tests.

Pensado para durarBuilt to last

Rust aporta seguridad de memoria sin recolector de basura. El proyecto prohíbe el código unsafe y somete el motor a pruebas automáticas de robustez frente a entradas hostiles. Rust brings memory safety without a garbage collector. The project forbids unsafe code and continuously stress-tests the engine against hostile input.

Abierto para sumarOpen to everyone

Licencia MIT/Apache, hoja de ruta pública y tareas de uno o dos días. Hay sitio para código, pruebas, documentación y diseño. MIT/Apache licence, a public roadmap and one-to-two-day tasks. There is room for code, tests, documentation and design.

Estado actualCurrent status

Dónde estamos, sin adornosWhere we are, plainly

Megi está en pre-alpha: ya convierte páginas reales en imágenes y ejecuta su JavaScript, pero todavía no es un navegador para el día a día. Esto es lo que hay hoy, sin promesas de calendario. Megi is in pre-alpha: it already turns real pages into images and runs their JavaScript, but it is not an everyday browser yet. This is what exists today, with no calendar promises.

Sin releases todavía: no hay instalador ni binarios oficiales; el motor se compila desde el código fuente. La ventana nativa ya compila y el modo sin pantalla está probado, pero aún no se ha verificado visualmente en un escritorio real. No releases yet: there is no installer or official binary; the engine is built from source. The native window compiles and headless mode is tested, but it has not been visually verified on a real desktop yet.

PruébaloTry it

Pruébalo en tu máquinaTry it on your machine

Todavía no hay instalador: el motor se compila desde el código fuente. Si sabes usar una terminal, en un par de minutos tienes tu primera imagen generada por Megi. There is no installer yet: the engine is built from source. If you can use a terminal, you will have your first Megi-made image in a couple of minutes.

Tu primera imagenYour first image

Necesitas Rust 1.88+ y Git. Clona el repositorio y renderiza la página de ejemplo: You need Rust 1.88+ and Git. Clone the repository and render the sample page:

bash
git clone https://github.com/juanpimg/Megi.git
cd Megi
cargo run -p render -- tests/fixtures/render/showcase/index.html \
  /tmp/megi.png --width 1024 --height 768

Obtendrás un PNG de 1024×768: el mismo que ves en la galería. La primera compilación tarda un poco. You will get a 1024×768 PNG: the same one you see in the gallery. The first build takes a while.

¿Y la ventana? En Linux con X11/Wayland, tools/megi.sh abre cualquier página. El modo sin pantalla también genera imágenes, sin abrir ventana. And the window? On Linux with X11/Wayland, tools/megi.sh opens any page. Headless mode also produces images, without opening a window.
